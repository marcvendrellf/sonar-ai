# MVP agent-structure direction

- Source type: user-supplied ChatGPT architecture recommendation
- Supplied in project chat: 2026-08-29

## Source recommendation

For a hackathon, avoid a large agent swarm. Use one code-owned orchestrator and a visible investment-committee flow:

```text
Portfolio Manager / orchestrator
  -> Fundamental Analyst
  -> Market / Context Analyst
  -> Risk Officer
  -> Bear / Devil's Advocate
  -> Portfolio Manager revision
  -> human decision
  -> Communications / Report Writer
```

The recommendation separates domain authority:

- Portfolio Manager owns capital allocation, not deep research or manual risk math.
- Fundamental Analyst evaluates company quality, valuation, financial strength, catalysts, and risks.
- Market / Context Analyst evaluates news, sector, macro, regulation, competitors, and material events.
- Risk Officer calls deterministic analytics and can hard-block mandate, data, or concentration breaches.
- Bear / Devil's Advocate attacks the proposal and flags uncertainty but cannot veto it.
- Communications / Report Writer runs after the investment decision and cannot influence allocation.

Use structured state and typed outputs, isolated agent context, deterministic portfolio comparison and stress tools, one focused portfolio decision, human approval, and no automatic execution. Cut swarms, autonomous web exploration, price forecasting, reinforcement learning, multiple MCP servers, distributed services, and long-term autonomous learning from MVP.
