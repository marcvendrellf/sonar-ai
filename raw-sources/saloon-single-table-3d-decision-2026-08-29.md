# Saloon single-table 3D decision

- Date: 2026-08-29
- Source: direct user decision in the project session
- Status: current frontend direction

## Decision

The first Saloon version uses one physical meeting table in a minimal 3D room.

The six agents appear as orbs using the visual language already defined for Sonar AI. The default camera shows the table and the agents gathered around it. Selecting an orb moves the camera to a frontal interview composition for that agent. The selected agent's details appear in a panel on the right.

The game-like quality comes from the room, camera, seating, orb state, and selection. It should not come from a dense game HUD, character statistics, chat bubbles, or a literal Western theme.

## Current scope

This capture records the design direction only. It does not authorize implementation.

The exact orb material, camera path, interview-panel fields, and fallback behavior remain implementation details to settle during the Saloon frontend epic.
