# User idea capture: agent-controlled hedge fund

- Source: user message in the project session
- Captured: 2026-08-28
- Status: immutable capture
- Visual reference: [agent fund visual reference](assets/agent-fund-visual-reference.png)

## Idea

A hedge fund controlled by an agent. Cala acts as the knowledge base. The agent reads news and, more importantly, uses Cala's relationships to understand how an event may propagate across companies and assets.

## Visual direction

The supplied reference uses:

- tall, sparse white panels with heavily rounded corners;
- a single glossy or iridescent sphere as the main visual object;
- restrained black and gray typography;
- deep blue gradients for active content;
- large quiet areas rather than a dense trading terminal;
- a "Thinking..." state paired with the sphere;
- an editorial, futuristic presentation rather than a conventional finance dashboard.

The reference is visual inspiration only. Its quantum-computing text and "Powered by Odor" wording are not part of the product concept.
