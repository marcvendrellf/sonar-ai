# Risk-preferences-only MVP direction

- Decision date: 2026-08-29
- Source: user clarification in project thread

The MVP accepts risk preferences only. User does not provide company names. Agents research through Cala, discover investable candidates from the Alpaca-available universe, recommend portfolio distribution, and—after explicit human approval and deterministic risk checks—submit the allocation to Alpaca Paper.

This is a product decision, not proof of Cala or Alpaca field coverage. Live API behavior still requires sanitized fixtures.
