# Saloon 3D asset provenance

Retrieved: 2026-08-29

This capture records every runtime asset used by the clay-diorama Saloon. All
files are stored inside the repository under `apps/web/public/` and load without
network access. No CDN, no Spline scene request, and no `@pmndrs/assets` HDRI is
used by the Saloon.

The visual target is the [clay-style decision](saloon-clay-style-decision-2026-08-29.md).
That direction rules out photoreal material packs, so the shipped room uses one
original model, flat clay colours, and a single subdued environment.

## Model

`apps/web/public/models/saloon/saloon-shell.glb` is original work for this
repository, not a downloaded asset. It is generated by
`apps/web/scripts/build-saloon-shell.mjs` and can be rebuilt with
`pnpm --filter web build:saloon-shell`.

It contains the static architecture and furniture only: a base slab, a back wall,
side walls that step down towards the open front, a low cutaway rim, one wall
niche, one wall slot, a scalloped table slab, and six seat plinths. Every part is
a rounded box or an eased lathe, built in world space and merged by material, so
the room is four meshes, 12,760 triangles, and 217 kB. It carries no textures,
no UVs, no lights, and no animation tracks; the four clay materials are created
and bound by material name at runtime in
`apps/web/features/saloon/saloon-shell.tsx`.

It is the only downloaded runtime asset. Drei `Environment` loads it at
`environmentIntensity={0.18}`, and every room material caps its own
`envMapIntensity` at 0.15, so it contributes almost nothing to the clay and
exists mainly to give the agent orbs something to reflect.

## Licence

Source: <https://polyhaven.com/license>

Observed facts:

- Poly Haven states that all assets on the site are released under CC0.
- The licence permits commercial use, modification, and redistribution.
- Attribution is not required. It is recorded here anyway so the team can answer
  a licence question during judging without re-deriving it.

No asset with unclear redistribution rights was used.

## Withdrawn

An earlier pass on the same branch downloaded four Poly Haven CC0 PBR texture
sets for a photoreal warm interior: `beige_wall_001`, `herringbone_parquet`,
`american_walnut_veneer`, and `poly_wool_herringbone`. The clay-style decision
rejected that direction, so the files were deleted from
`apps/web/public/textures/saloon/` rather than left unused. They are recorded
here in case the team ever wants to compare the two treatments: each set is the
1K JPG `diff`, `arm`, and `nor_gl` variant from
`https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/<slug>/`.

## Rejected sources

- Spline community scenes: the documented GLTF/GLB export drops lighting,
  environment, post-processing, and several material features, and
  colour-and-texture export is a paid feature. See the
  [3D authoring references](saloon-3d-authoring-references-2026-08-29.md).
- threecn scenes: the observed catalogue holds procedural effects, not a room.
- `@pmndrs/assets` apartment HDRI: still bundled for other surfaces, but it is
  the cool product-photography environment the rebuild was asked to remove.
- Stock model marketplaces: no asset was used whose redistribution terms could
  not be read from a published licence page.
