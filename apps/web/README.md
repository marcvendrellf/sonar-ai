## Getting started

Install dependencies and start the development server from the repository root:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. The dashboard route is composed from `app/page.tsx` and `features/dashboard/dashboard.tsx`.

Run the repository checks from the root:

```bash
pnpm typecheck
pnpm lint
pnpm build
```

This repository uses pnpm exclusively. Do not use npm, Yarn, or Bun commands.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
